# ชำระผ่าน Bill Payment ธนาคารกรุงไทย

เอกสารนี้ใช้แจ้งรูปแบบเลขอ้างอิงกับธนาคาร และใช้ตั้งค่าระบบ

## ข้อมูลที่ต้องได้จากธนาคาร

| ค่า | ใช้ทำอะไร | ตั้งใน |
|---|---|---|
| เลขผู้เสียภาษีของเทศบาล 13 หลัก | ส่วนแรกของบาร์โค้ด | `BILLER_TAX_ID` |
| Suffix 2 หลัก (เช่น `00`) | ต่อท้ายเลขผู้เสียภาษี รวมเป็น Biller ID 15 หลัก | `BILLER_SUFFIX` |
| Comp Code | ใช้กับเมนู "จ่ายบิล" ใน Krungthai NEXT (ไม่ได้อยู่ในบาร์โค้ด) | `KTB_COMP_CODE` |

## รูปแบบบาร์โค้ดและ QR

ใช้มาตรฐานบาร์โค้ดชำระบิลของสมาคมธนาคารไทย (Code 128) และใน QR "ชำระผ่าน Mobile Banking" เก็บข้อความเดียวกับบาร์โค้ด ตรวจกับแบบฟอร์มตัวอย่างของกรุงไทย (ใบแจ้งภาษีที่ดินของเทศบาล) แล้ว รูปแบบตรงกัน ส่วน Comp Code, Suffix และความยาว Ref ของค่าขยะ ยังรอค่าจริงจากธนาคาร

```
|<Biller ID 15 หลัก><CR><Ref1><CR><Ref2><CR><ยอดเงินหน่วยสตางค์ ไม่มีจุด>
```

`<CR>` คือตัวขึ้นบรรทัด (ASCII 13) ซึ่งบนแบบฟอร์มพิมพ์จะแสดงเป็นเว้นวรรค ตัวอย่างยอด 50.00 บาท เขียนเป็น `5000`

## รูปแบบ Ref1 / Ref2 ที่ต้องแจ้งธนาคาร

**ทั้งสองช่องเป็นตัวเลขล้วน ยาว 18 หลักคงที่ (เท่ากับแบบฟอร์มตัวอย่าง) ขึ้นต้นด้วย `00` และบังคับใส่ทั้งคู่** ถ้าธนาคารกำหนดความยาวอื่น แจ้งมาเพื่อปรับ

**Ref.1 — รหัสผู้ชำระ (คงที่ตลอดปีงบประมาณ)**

| หลัก | ความหมาย |
|---|---|
| 1–2 | `00` |
| 3–6 | ปีงบประมาณ พ.ศ. เช่น `2570` |
| 7 | ชนิดรหัสลูกค้า (`1` = รหัสตัวเลข, `2` = รหัสจาก AppSheet) |
| 8–17 | รหัสลูกค้า 10 หลัก |
| 18 | เลขตรวจสอบ (Luhn) |

**Ref.2 — เลขรายการชำระ (ไม่ซ้ำกันในแต่ละครั้ง)**

| หลัก | ความหมาย |
|---|---|
| 1–2 | `00` |
| 3–8 | วันที่สร้างรายการ ปปดดวว (พ.ศ. 2 หลัก) |
| 9–12 | เดือนที่ชำระ (ค่ารวมแบบบิต ต.ค. = 1, พ.ย. = 2, ธ.ค. = 4 … ก.ย. = 2048) |
| 13–17 | เลขสุ่ม |
| 18 | เลขตรวจสอบ (Luhn) |

ระบบแปลงเลขทั้งสองกลับเป็นบ้านและเดือนที่ชำระได้เอง ไม่ต้องมีฐานข้อมูลเพิ่ม เมื่อได้ไฟล์รายงานการรับชำระจากธนาคาร จึงจับคู่กับบ้านได้อัตโนมัติ เลขตรวจสอบหลักสุดท้ายช่วยกันกรณีพิมพ์ผิดตอนกรอกเองในแอป

ตัวอย่าง (ยอด 25.00 บาท): `|099400046246855 002570100000052930 006910020001473903 2500`

**ค่าต้นแบบที่ใช้อยู่ตอนนี้** (นำมาจากแบบฟอร์มตัวอย่างของธนาคาร ซึ่งเป็นของภาษีที่ดิน): เลขผู้เสียภาษี `0994000462468`, Suffix `55`, Comp Code `444588` ต้องเปลี่ยนเป็นค่าของค่าขยะเมื่อธนาคารส่งมา

## ข้อที่ต้องถามธนาคารเพิ่ม

1. Comp Code และ Suffix ของค่าขยะ (แยกจากของภาษีที่ดิน) และยืนยันว่ารับ Ref1/Ref2 ตัวเลข 18 หลักตามรูปแบบนี้ได้
2. ไฟล์รายงานการรับชำระรายวันจาก KTB Corporate Online มีรูปแบบอย่างไร (ขอไฟล์ตัวอย่าง) เพื่อทำระบบนำเข้าและจับคู่อัตโนมัติ
3. มีบริการแจ้งผลการชำระแบบ Online/Real-time หรือ API ที่เปิดแอป Krungthai NEXT พร้อมยอดได้หรือไม่
