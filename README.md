# ระบบค่าบริการขยะ — เทศบาลตำบลเหมืองหม้อ

เว็บสำหรับประชาชน: ค้นหาบ้าน ดูยอดค้างรายเดือน เลือกเดือนแล้วเลือกธนาคาร ระบบเปิดแอปธนาคารพร้อมยอดที่ล็อกไว้และยืนยันการชำระให้อัตโนมัติ หรือจะสแกน QR พร้อมเพย์แล้วส่งสลิปให้เจ้าหน้าที่ตรวจใน AppSheet ก็ได้

ใช้ Next.js (App Router) และใช้ Google Sheets เป็นฐานข้อมูล ดูขั้นตอนตั้งค่าได้ที่ [docs/SETUP.md](docs/SETUP.md)

## เริ่มใช้งานในเครื่อง

```
npm install
cp .env.example .env.local   # ใส่ ORDER_SECRET อย่างน้อย
npm run dev
```

ถ้ายังไม่ได้ตั้งค่าสิทธิ์ Google ระบบจะอ่านชีตผ่านลิงก์สาธารณะได้ แต่ยังรับสลิปไม่ได้

## โครงสร้าง

- `app/api/households` — ค้นหาบ้าน (คืนเฉพาะชื่อ บ้านเลขที่ และหมู่) และดูสถานะรายเดือน
- `app/api/orders` — คำนวณยอดจากชีตที่ฝั่งเซิร์ฟเวอร์ ลงลายเซ็นรายการ และสร้าง QR พร้อมเพย์
- `app/api/payments` — เปิดแอปธนาคารผ่าน Gateway (Opn) รับผลจากหน้า return และ webhook แล้วบันทึกลงแท็บ `slip`
- `app/api/slips` — ตรวจรายการ ตรวจไฟล์ เช็กการส่งซ้ำ แล้วอัปโหลดลง Drive และเพิ่มแถวในแท็บ `slip`
- `lib/server/ktb-bill.ts` — บาร์โค้ด/QR ชำระบิลกรุงไทย และการเข้ารหัส/ถอดรหัส Ref1/Ref2 ([รายละเอียด](docs/KTB-BILL-PAYMENT.md))
- `lib/billing.ts` — กติกาสถานะรายเดือนและลำดับการเลือกเดือน
- `lib/server/` — การเชื่อมต่อ Google, การอ่านชีต และ PromptPay

## กติกาสถานะรายเดือน (อ่านจาก `payment_DATA`)

- **ยกเว้น** — เดือนก่อนเดือน/ปีที่เริ่มชำระ, หมายเหตุมีคำว่า "ยกเว้น" หรือยอด "ที่ต้องจ่าย" เป็น 0
- **ชำระแล้ว** — คอลัมน์ชื่อเดือนมียอดมากกว่า 0 หรือมีสลิปที่มี ✅
- **รอตรวจสอบ** — มีสลิปในแท็บ `slip` ที่สถานะยังว่าง
- **ค้างชำระ** — กรณีอื่นนอกจากที่กล่าวมา ยอดใช้ค่าจากคอลัมน์ "ที่ต้องจ่าย" ของเดือนนั้น
